========================================
 CALCULADORA AVANCADA COM IMPRESSAO
 JLS SOFT AI FACTORY
========================================

COMO USAR:
1. Dê duplo clique no arquivo "index.html" para abrir no navegador.
   Nenhuma instalação ou servidor é necessário.

FUNCIONALIDADES:
- Insira valores numéricos (inteiros, decimais, negativos) no campo "Digite um número"
  e clique no botão [+] ou pressione Enter para adicionar à coluna.
- Selecione a operação matemática: Soma (+), Subtração (−), Multiplicação (×) ou Divisão (÷).
- Ajuste o título do documento, a data (DD/MM/AAAA) e a hora (HH:MM) manualmente.
  Os campos são preenchidos automaticamente com a data/hora atual, mas podem ser editados.
- Clique em [Calcular] para obter o resultado da operação sobre todos os valores da coluna.
- Clique em [Pré-visualizar] para ver o layout do documento antes de imprimir.
- Clique em [Imprimir] para abrir o diálogo de impressão do sistema, onde você pode
  selecionar a impressora desejada (USB, rede local, PDF etc.).
- Clique em [Limpar] para reiniciar todos os campos.

OBSERVAÇÕES:
- Os dados inseridos são mantidos durante a sessão (até fechar o navegador).
- A seleção de impressora é feita pelo diálogo nativo do Windows/macOS.
- Funciona nos navegadores: Chrome, Edge, Firefox, Safari.
